Current component `frontend/src/components/FilterFunnel.vue` (125 lines) renders a 4-level nested tree (service -> provider -> account -> metric) as chips connected by CSS border-left "guide lines" (see its `<style>` block: `.funnel-branch`, `.funnel-branches`, `.funnel-leaves`). The user wants this reimagined as an actual Sankey (or "alluvial") diagram: nodes at each stage (service, provider, account, metric) with flows/links between adjacent stages, so a metric shared by multiple accounts naturally shows as ONE node with multiple incoming links converging into it — Sankey diagrams handle exactly this convergence naturally, unlike a strict tree.
